## 发布目标

发布 Desktop 中英文界面切换：默认跟随已保存偏好或系统语言，用户可从 Footer 左侧切换并持久化；
Footer 右侧显示当前版本和“检查更新”，保持已有 Tauri updater 安全链路不变。
