- 日期：2026-08-15
- 状态：审核中（deferred publishing）
- Plane：LISTENUP-20
- 配套 Desktop：LISTENUP-19 / `v0.5.2`

## 发布目标

把仓库中已经完成的 Native Messaging v5 Extension 作为 `1.5.3` 上传到现有 Chrome Web
Store 条目。该版本 cursor 带 `playbackEpoch`，用于区分新的播放世代；Desktop `0.5.2` 已先行
兼容 v4/v5，因此商店审核与分阶段发布期间，新旧 Extension 均能正常显示字幕。

- 商店不接受重复的 1.5.2，因此必须递增版本；版本唯一来源仍是
  `apps/extension/package.json`。

  `listenup-dev`。
- 提交审核前必须关闭自动发布。审核通过后先停留在 staged 状态，Desktop 0.5.2 的正式资产
  验证完成后再手动发布。
