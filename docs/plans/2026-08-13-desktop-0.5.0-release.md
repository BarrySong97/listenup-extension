# ListenUp Desktop 0.5.0 Embedded 悬浮字幕发布

- 日期：2026-08-13
- 状态：完成
- Plane：LISTENUP-16
- 功能与修复：LISTENUP-15
- 实施计划：`docs/plans/2026-08-13-desktop-embedded-subtitle-overlay.md`

## 发布目标

把 Desktop 同窗 YouTube 播放区的可拖动悬浮字幕、透明字幕卡，以及与悬浮字幕互不联动的
底部字幕收起控制发布给官网新安装用户和 0.4.1 应用内更新用户。用户可以只收起底部字幕，
不必同时显示视频上的悬浮字幕；也可以独立组合底部列表与 Overlay。

## 发布范围

- Desktop 版本从 0.4.1 升到 0.5.0；Extension 与 Website 版本不变。
- 同步 `package.json`、Tauri 配置、Cargo manifest / lockfile 与 Desktop 发布基线文档。
- 推送 annotated tag `v0.5.0`，由 `release-desktop.yml` 构建 Apple Silicon DMG、updater
  `.app.tar.gz`、minisign 签名和 `latest.json`，全部成功后自动公开 Release。
- Chrome Web Store 不随本次发布更新；BrowserSource native messaging 协议保持不变。

## 风险与回归

- 正式构建必须来自干净 tag；workflow 任一步失败应保持 draft，不手工公开不完整资产。
- `latest.json` 必须指向 `github.com/.../releases/download/v0.5.0/`，不能使用 GitHub assets API。
- 发布资产必须包含 DMG、updater `.app.tar.gz`、签名和 `latest.json`；签名/公证状态以 workflow
  与 Release 资产为准。
- 本地 DEV bundle 仅用于交互回归，发布前必须清理仓库 `target` 下 bundle，正式资产只认 tag CI。
