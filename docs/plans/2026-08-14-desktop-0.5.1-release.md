# ListenUp Desktop 0.5.1 浏览器字幕重接修复发布

- 日期：2026-08-14
- 状态：执行中
- Plane：LISTENUP-18
- 修复：LISTENUP-17

## 发布目标

发布 Desktop 退出自播后，浏览器刷新可重新激活字幕来源的修复。刷新产生的新 session 即使尚未
播放，也应恢复字幕快照；同一 bridge + tab 的旧 session 不得残留为幽灵播放候选。

## 发布范围

- Desktop 版本从 0.5.0 升到 0.5.1；Extension 与 Website 版本不变。
- 同步 `package.json`、Tauri 配置、Cargo manifest / lockfile 与 Desktop 发布基线文档。
- 推送 annotated tag `v0.5.1`，由 `release-desktop.yml` 构建 Apple Silicon DMG、updater
  `.app.tar.gz`、minisign 签名和 `latest.json`，全部成功后自动公开 Release。
- Native Messaging 协议版本与 production / DEV 环境标识不变。

## 风险与回归

- 正式构建必须来自干净 tag；workflow 任一步失败应保持 draft，不手工公开不完整资产。
- `latest.json` 必须指向 `github.com/.../releases/download/v0.5.1/`，不能使用 GitHub assets API。
- 发布资产必须包含 DMG、updater `.app.tar.gz`、签名和 `latest.json`。
- 本地不构建 bundle；正式资产只认 tag CI，仓库 `target` 下不得残留可被 LaunchServices 登记的 app。
