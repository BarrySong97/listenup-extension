## 发布目标

发布 Desktop 中英文界面切换：默认跟随已保存偏好或系统语言，用户可从 Footer 左侧切换并持久化；

## 风险与回归

- 语言切换不能改变 Native Messaging、字幕 session、内嵌播放或 updater 状态机；发布前保留现有
  TypeScript 与 Rust 回归集。
- Footer 在 340px 最小宽度下仍需保持语言入口与版本 / 更新入口可操作，长英文状态不能挤压布局。
- workflow 任一步失败保持 draft，不手工公开不完整资产；正式资产只认 tag CI。
