# ListenUp Desktop 0.4.0 同窗 YouTube 发布

- 日期：2026-08-11
- 状态：已完成
- Plane：LISTENUP-7
- 扩展回归：LISTENUP-8
- 实施计划：`docs/plans/2026-08-10-desktop-embedded-youtube-player.md`

## 发布目标

把 Desktop 同窗官方 YouTube iframe、独立字幕 transport、手动 Cookie Keychain 与双来源仲裁
发布给官网新安装用户和 0.3.4 应用内更新用户。输入链接后继续使用同一个 `main` 窗口、原有
Desktop layout 与字幕组件，不改变窗口尺寸；退出后保持空态，等待下一次浏览器播放。

## 发布范围

- Desktop 版本从 0.3.4 升到 0.4.0；Extension 与 Website 版本不变。
- 同步 `package.json`、Tauri 配置、Cargo manifest / lockfile 与 Desktop 发布基线文档。
- 推送 annotated tag `v0.4.0`，由 `release-desktop.yml` 构建 Apple Silicon DMG、updater
  `.app.tar.gz`、minisign 签名和 `latest.json`，全部成功后自动公开 Release。
- 第二个 macOS 大版本、30 分钟播放、广告、1080p 菜单和 Keychain 重启恢复不冒充本次已验证，
  继续由 Plane `LISTENUP-8` 跟踪。

## 风险与回归

- 正式构建必须来自干净 tag；workflow 任一步失败应保持 draft，不手工公开不完整资产。
- `latest.json` 必须指向 `github.com/.../releases/download/v0.4.0/`，不能使用 GitHub assets API。
- 发布资产必须包含 DMG、updater `.app.tar.gz`、签名和 `latest.json`；签名/公证状态以 workflow
  与 Release 资产为准。
- YouTube iframe 或字幕接口可能随平台变化；0.4.0 的安全边界和已知扩展回归见 ADR-0015 与
  Plane `LISTENUP-8`。
