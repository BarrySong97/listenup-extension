## 风险与回归

- 正式构建必须来自干净 tag；本地 DEV/HMR 显示 Tooltip 不能代替 production 验收。
- `latest.json` 必须指向 `github.com/.../releases/download/v0.3.4/`，不能退回 GitHub assets API。
- Release workflow 任一步失败应保持 draft，不允许手工公开不完整资产。
- 0.3.3 用户安装更新后应用会重启；重启后的 Tooltip 才是 updater 路径最终验收。
