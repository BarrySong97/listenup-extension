# 页面模块文档索引

>
> 源码路径: `src/pages/`
>
> 覆盖范围: 页面级模块导航，不覆盖共享组件或系统配置

## 源码定位

- 主路径: `src/pages/`
- 相关路径: `src/components/ui/`

- [content/](content/README.md): YouTube 内容脚本和字幕面板，是仓库最重要的模块

- [newtab/](newtab/README.md): UI Preview 页面，复用内容脚本组件进行调试
- [devtools/](devtools/README.md): DevTools 面板入口
