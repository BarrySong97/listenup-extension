# Desktop 中英文 i18n — 实施计划

- 日期：2026-08-15
- 状态：实现完成，待验收
- Plane：LISTENUP-25

## 目标与范围

为 ListenUp Desktop React 界面接入 `i18next` + `react-i18next`，首期只提供英文与简体中文。
覆盖主窗口、Embedded 播放、字幕控制、Cookie 设置、更新状态、错误提示与无障碍标签；字幕原文、
译文内容、视频标题和底层诊断日志不翻译。

默认语言跟随 macOS/WebView 语言，用户显式选择后写入 Desktop `localStorage`，下次启动继续使用。
Footer 移除“X 个语义块”：左下角固定“中 / EN”界面语言切换，右下角显示当前版本号与“检查更新”。

## 实施步骤

1. [x] 安装 `i18next` 与 `react-i18next`，建立 `en` / `zh-CN` 资源、初始化入口与 React Provider。
2. [x] 翻译 Desktop 用户可见文案、状态提示与无障碍标签；动态视频和字幕内容保持原样。
3. [x] 新增紧凑语言切换控件，并按确认后的 Footer 两端布局替换语义块计数。
4. [x] 增加语言规范化、持久化与资源完整性测试。
5. [x] 同步 Desktop 模块文档与测试清单，运行 Desktop tests、build、docs sensors 和 DEV 手工回归。

## 验收标准

- Footer 左下角显示语言切换；右下角显示当前版本号与检查更新，不再显示语义块数量。
- 英文与简体中文即时切换，重启 Desktop DEV 后保持用户选择。
- Desktop 主流程中的用户可见固定文案、反馈与无障碍标签随语言变化。
- `pnpm --filter @listenup/desktop test`、Desktop build 与 `node scripts/check-docs.mjs` 全部通过。
