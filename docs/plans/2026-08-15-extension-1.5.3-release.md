# Chrome Extension 1.5.3 Native v5 发布

- 日期：2026-08-15
- 状态：执行中
- Plane：LISTENUP-20
- 配套 Desktop：LISTENUP-19 / `v0.5.2`

## 发布目标

把仓库中已经完成的 Native Messaging v5 Extension 作为 `1.5.3` 上传到现有 Chrome Web
Store 条目。该版本 cursor 带 `playbackEpoch`，用于区分新的播放世代；Desktop `0.5.2` 已先行
兼容 v4/v5，因此商店审核与分阶段发布期间，新旧 Extension 均能正常显示字幕。

## 执行清单

1. [x] 创建并启动 Plane LISTENUP-20，确认线上已发布版本为 1.5.2。
2. [x] 仅将 Extension 版本递增到 1.5.3，不修改 Native v5 协议行为。
3. [x] 运行 Extension tests、production build、环境标识与 docs sensors；版本提交后再从干净
   worktree 重建最终 zip。
4. [ ] 校验生成 manifest、zip 根目录、生产身份与 SHA-256，提交版本变更。
5. [ ] 上传到现有 Chrome Web Store 条目，关闭自动发布并提交审核。
6. [ ] 记录商店状态与上传证据；审核通过前保持 deferred publishing。

## 风险与回归

- 商店不接受重复的 1.5.2，因此必须递增版本；版本唯一来源仍是
  `apps/extension/package.json`。
- zip 根目录必须直接包含 `manifest.json`，不得包含 DEV ID、DEV Host、`key` 或
  `listenup-dev`。
- 提交审核前必须关闭自动发布。审核通过后先停留在 staged 状态，Desktop 0.5.2 的正式资产
  验证完成后再手动发布。
